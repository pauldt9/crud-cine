# crud-cine

Aplicación de escritorio para la administración y gestion de un cine.
Permite al administrador gestionar películas, salas funciones y cuentas de
taquilleros, y consultar y exportar reportes de ventas. Los taquilleros
realizan la venta de boletos seleccionado función y asientos.

## Tecnologías
Java, Java Swing con Flatlaf, MySQL, jBCrypt, iText 8

## Requisitos
- Java 23 o posterior
